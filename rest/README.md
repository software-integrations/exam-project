# REST

- [ ] Implement at least three GET endpoints that return collections. Each supports search and pagination.
- [ ] Implement at least three GET endpoints that return one item by ID.
- [ ] Implement at least one POST, one PUT and one DELETE endpoint.
- [ ] Implement login and logout endpoints.
- [ ] Satisfy all mandatory REST constraints, including HATEOAS with contextual links.
- [ ] Follow the [REST resource naming convention](https://restfulapi.net/resource-naming/) and the class exercises.
- [ ] Version the API using a format of your choice.
- [ ] Use OAuth2 with JWT for authentication.
- [ ] Choose a token revocation strategy and implement it in a key-value store independent of the API database.
- [ ] Provide a test suite in Postman or a similar tool with positive and negative cases.

See the [shared exam requirements](../README.md#shared-requirements).
